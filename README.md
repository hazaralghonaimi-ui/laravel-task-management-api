# Laravel Task Management API

A Task Management REST API built with Laravel 13 as a practical learning project.

## About the Project

This project was implemented as part of a practical Laravel course to develop my understanding of backend web development and RESTful API development.

The project focuses on managing tasks and applying Laravel concepts through hands-on practice.

## Technologies Used

- PHP
- Laravel 13
- MySQL
- RESTful APIs
- Eloquent ORM
- Git and GitHub
- Postman

## Key Concepts

- MVC Architecture
- CRUD Operations
- Database Migrations
- Eloquent ORM and Database Relationships
- API Routing and Controllers
- Request Validation

## Project Structure

- `app/Http/Controllers`: Handles application requests and logic.
- `app/Models`: Defines the application's data models.
- `app/Http/Requests`: Handles request validation.
- `app/Http/Resources`: Structures API responses.
- `routes/api.php`: Defines API routes.
- `database/migrations`: Defines the database structure.
- `database/seeders`: Provides sample data.

## Learning Objectives

- Understand Laravel backend development.
- Build and organize RESTful APIs.
- Work with relational databases.
- Apply Laravel's MVC architecture.
- Practice API testing and database operations.
